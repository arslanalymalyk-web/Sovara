# Design references

`awesome-design-md/` holds 84 ready-made `DESIGN.md` analyses of real websites (from
https://github.com/voltagent/awesome-design-md, MIT, copied at its default branch HEAD).

To use one, copy the brand's `DESIGN.md` to the project root and tell the agent to build to it.
They are kept here, not at the root, on purpose: Hallmark and Impeccable treat a root `DESIGN.md`
as a locked design system that overrides everything else, so a stray copy would silently restyle
the project. The RGS portal has no root `DESIGN.md` today.
